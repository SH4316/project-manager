클라이언트설정
Claude Codeclaude mcp add --transport http sandol <MCP_URL>/mcp --header "Authorization: Bearer <TOKEN>"
Codex CLI~/.codex/config.toml에 [mcp_servers.sandol] url = "<MCP_URL>/mcp" bearer_token_env_var = "SANDOL_TOKEN" 추가, 환경 변수 SANDOL_TOKEN=<TOKEN>
